# AIaC Project Profile

- Loại dự án: desktop-app.
- Dấu hiệu: dự án Electron/Tauri Desktop App (VuaOffice / VuaAssistant).
- Kỹ năng chuyên biệt: 360-desktop-app.
- Agent map: `.claude/aiac/index/agent-map.md` là bản đồ symbol/domain mặc định để chọn nơi đọc/sửa.
- Codegraph: `.claude/codegraph.md` là cache import nhẹ; `.codegraph/` upstream chỉ dùng deep mode.
- Học theo dự án: ECC lưu tóm tắt phiên, quan sát và kỹ năng học được; AIaC chỉ nạp phần phù hợp, có giới hạn context.

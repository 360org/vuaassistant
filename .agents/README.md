# Project Development Skills

This directory contains workflows for agents that work on this repository.

`skills/vuaassistant-dev-skills` is a relative symlink to the shared development
skill source at `../SKILLS/vuaassistant-dev-skills/skills`. It intentionally
stays linked so workflow updates are available to this project immediately.

The repository-level `skills/` directory is separate: those are skills loaded
by the VuaAssistant application for end users.
